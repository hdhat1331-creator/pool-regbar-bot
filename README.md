# Pool Regbar Bot

نسخه بازنویسی‌شده ربات با Flask، Telegram Bot API و Supabase.

## راه‌اندازی

1. `.env.example` را به `.env` تبدیل کنید.
2. مقادیر `BOT_TOKEN` و `SUPABASE_KEY` را در `.env` قرار دهید.
3. وابستگی‌ها را نصب کنید:
   `pip install -r requirements.txt`
4. اجرا:
   `python app.py`

حالت ادمین شامل گزینه «👤 رفتن به صفحه کاربر عادی» و در حالت کاربر عادی گزینه «👑 بازگشت به پنل ادمین» است.

این نسخه ارسال پیام تکراری/انبوه خودکار به یک کاربر را پیاده‌سازی نمی‌کند.
